# 갈림길 모퉁이 주택 — 설계 기록

- 근거 취향: [taste-profile.md](taste-profile.md) (참고 이미지 1장, 복제가 아닌 공통 특징만 사용)
- 구현: `web/seed_townhouse.py` · 26.3 블록만 사용 (`template_format.state()`)

## 설계 방향

길을 향해 박공(삼각 지붕면)을 세운 키 큰 본채에, 한쪽에는 낮은 교차 박공 날개, 다른 쪽에는 작업용 처마를 붙이고,
뒤쪽의 높은 벽돌 굴뚝 하나로 전체를 묶는다.

## 덩어리 구성

| 부분 | 위치/크기 | 이유 |
|---|---|---|
| 본채 | x 0..10, z 0..9 · 돌 1층 + 반목조 2층 | 가장 크고 높은 중심. 정면 박공으로 길에서 바로 읽힘 |
| 동쪽 날개 | x 11..17, z 2..8 · 1.5층 | 본채보다 낮아 위계가 생기고, 지붕 방향이 직각이라 지붕선이 겹침 |
| 돌출창 | 본채 2층 정면 가운데 | 정면의 시선 집중점 |
| 서쪽 처마 | x -4..-1 | 반쯤 열린 작업 공간, 좌우 비대칭 균형 |
| 굴뚝 | 본채 뒤 바깥 | 지붕 위로 솟는 세로 포인트 |

## 재료 역할

| 역할 | 블록 |
|---|---|
| 기초·1층 | 조약돌 위주 + 돌벽돌·안산암, 아래쪽 이끼 낀 조약돌, 모서리 다듬은 안산암 |
| 골조 | 껍질 벗긴 참나무 통나무 |
| 벽 채움 | 방해석 (흰 회벽) |
| 지붕 | 심층암 타일 계단/블록/반블록, 처마 띠는 가문비나무 |
| 강조 | 벽돌 굴뚝, 가문비나무 덧창, 꽃 핀 진달래 화단, 랜턴 |

## 다듬으며 바꾼 점

- 2층 대각선 가새 → 글자처럼 지저분하게 보여서 2칸 창 + 화단으로 교체
- 박공 맨 아래 들보 → 2층 위 들보와 두 줄로 겹쳐 무거워 보여서 회벽으로 교체
- 서쪽 지붕창 → 서로 다른 방향 지붕이 엉켜 구멍처럼 보여서 이번 버전에서는 제외
