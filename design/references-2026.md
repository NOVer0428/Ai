# 스타일별 이미지 레퍼런스 관찰 (핀터레스트, 2026-11-14)

핀터레스트 검색 결과 이미지만 보고 정리한 **공통 특징**이다. 특정 작품을 복제하지 않고 문법만 쓴다.
건축 파일(스케매틱 등)은 받지 않았다.

## 외형

| 스타일 | 반복해서 보인 특징 |
|---|---|
| 일본식 찻집 | 어두운 나무 골조 + 흰 창호 판, 회색 기와가 처마 끝에서 살짝 들림, 여러 단 지붕, 문 앞 천(노렌)·등, 물 위로 띄운 툇마루, 붉은 포인트, 분재·벚나무 |
| 오층탑 | 층마다 넓은 처마(위로 갈수록 좁아짐), 붉은 기둥·난간, 어두운 기와 또는 청록 구리 지붕, 처마 모서리 등, 꼭대기 금색 상륜, 돌 기단 + 계단 |
| 모던 빌라 | 흰 콘크리트 + 큰 유리 + 어두운 창틀, 위층이 튀어나온 캔틸레버, 나무 판 마감, 조명 있는 수영장, 층진 평지붕, 테라스 화분 |
| 모던 카페 | 벽돌/어두운 나무 정면, 줄무늬 차양, 큰 가게 창, 줄 조명, 바깥 테이블, 화분 |
| 구리 공방 | 구리 + 벽돌, 산화된 청록 포인트, 구리 모자 씌운 굴뚝 여러 개, 톱니 지붕, 둥근 창/톱니바퀴 장식, 실내 기계 |
| 시계탑 | 높은 탑 + 흰 원형 시계판, 청록 구리 첨탑, 작은 모서리 탑, 단계적으로 좁아지는 몸체 |
| 고딕 예배당 | 회색 돌, 높은 첨탑, 버팀벽, 뾰족 아치 창(따뜻한 불빛), 장미창, 가파른 어두운 지붕, 세로 강조 |
| 마녀 오두막 | 물 위 기둥, 마녀 모자처럼 휘어진 높은 뾰족 지붕, 이끼, 비뚤어진 굴뚝, 랜턴, 보라·청록 포인트 |
| 드워프 대장간 | 바위산에 박힌 형태, 심층암·흑암, 구리/벽돌 굴뚝 기둥, 용암 수로와 주황 불빛, 무거운 아치, 금 장식 |
| 엘프 나무집 | 거대한 줄기와 뿌리, 줄기 둘레의 작은 둥근 집 + 원뿔 지붕, 나선 통로, 잎 덮개, 덩굴·등불 |
| 지중해 빌라 | 크림/흰 벽, 붉은 기와 지붕, 아치 회랑, 발코니, 분홍 꽃 덩굴, 파란 덧창, 안뜰, 작은 탑 |
| 사막 시장 | 사암 계단식 평지붕, 줄무늬 천 차양(빨강/흰, 파랑/흰), 노점 진열(통·항아리), 돔 탑, 깃발 |
| 등대 | 빨강·흰 줄무늬 원통(위로 좁아짐), 검은 등롱실 + 유리 + 난간 발코니, 바위 기단, 붙은 관리인 집 |
| 바이킹 롱하우스 | 땅 가까이 내려오는 긴 지붕, 박공 끝 X자로 교차한 장식(용머리), 가문비·짙은 참나무, 이끼/풀 지붕, 돌 기단, 조각 문틀 |
| 풍차 | 위로 좁아지는 몸체(돌 기단 + 나무/회벽 위쪽), 모자 지붕, 큰 4날개(흰 천·격자), 붙은 방앗간 |

## 실내

| 스타일 | 반복해서 보인 특징 |
|---|---|
| 일본식 | 어두운 나무 천장 격자, 다다미 느낌 바닥(밝은 판 + 어두운 테두리), 바닥에 낮게 꺼진 탁자 + 방석, 종이 등, 창호 칸막이, 도코노마(벽감)에 분재 |
| 모던 | 트인 거실·주방, 밝은 상판 아일랜드 + 어두운 수납장, 체크/밝은 바닥, 소파(계단+카펫), 큰 창, 화분, 숨긴 조명 |
| 판타지/아늑함 | 벽난로, 체크·무늬 러그, 책장·물약 선반, 촛불, 매단 등, 가마솥, 덩굴, 보라 포인트 |
| 공방/대장간 | 작업대 줄, 용광로·모루·숫돌, 벽면 도구 선반, 파이프, 주황 불빛 |
