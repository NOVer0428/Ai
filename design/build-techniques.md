## 1. 구조: "서 있을 수 있는가"

- 바깥으로 내민 부분(캔틸레버, 발코니, 2층 돌출)은 밑에 **기둥·까치발·보**를 둔다. 떠 보이면 안 된다.
- 지붕이 넓으면 실내에 **칸막이벽이나 기둥**이 있어야 자연스럽다. 통짜 빈 공간은 피한다.
- 높은 건물은 **아래가 두껍고** 위로 갈수록 얇아진다(기단 → 몸체 → 꼭대기).
- 여러 덩어리는 서로 **붙어서** 이어져야 한다.
- → `qa.strict_check`의 "떠 있는 블록"이 일부를 잡는다. 돌출부 밑 받침은 눈으로 본다.

## 2. 벽: 깊이(depth)

- 평평한 벽은 **한 칸만 들여도** 가장자리에 그림자가 생겨 바로 나아진다.
- 깊이는 **여러 층**으로 쌓는다. 예: 뒤판(벽) → 창틀·아치 → 앞으로 나온 기둥. 큰 건물일수록 층이 많다(3~7층).
- 깊이 층은 **초점(현관·큰 창)으로 모이게** 배치해 시선을 끈다.
- 한 칸이 아니어도 깊이가 된다. **트랩도어, 담장(wall), 울타리, 들인 문·창**이 반 칸짜리 깊이다.
- 균형: 벽을 안으로 들일수록 **실내가 줄어든다**. 작은 집은 깊이를 바깥쪽(기둥·처마를 내미는 방향)으로 준다.
- 담장 블록은 안쪽에서 보면 가구와 이어져 어색해진다. 실내가 있는 벽에는 담장 대신 트랩도어를 쓴다.
- 벽면에 **세로줄(기둥·필라스터)** 을 일정 간격으로 넣으면 넓은 면이 나뉜다. 모던 건물에도 통한다.
- 현실 주택은 **안쪽 벽 재료가 바깥과 다르다**. 공간이 되면 벽을 2칸으로 하고 안팎 재료를 나눈다.
- → 도구: `Arch.recessed_window`, `pilaster`, `cornice`, `arch_window`. 기준 예시 `family_house`는 창(`_win`)이 벽면과 같은 면에 있고 기둥·띠 같은 벽 장식이 없다. 기단 띠와 현관 캐노피 말고는 벽이 평평하다.

## 3. 지붕

- 지붕은 비를 막는다. **경사**가 있고 벽보다 **바깥으로 나와야**(처마) 한다. 벽에 딱 맞춘 지붕은 어색하다.
- 꼭대기를 장식하려면 박공 폭을 **홀수**로 잡아 용마루가 한 칸이 되게 한다.
- 형태:
  - A자 지붕: 계단 → 옆에 뒤집힌 계단 → 그 위 블록을 반복한다. 용마루에는 뒤집힌 계단을 놓는다. 중세·판타지 주택에 쓴다.
  - 휜 지붕: A자로 시작해 위로 갈수록 반블록·계단으로 완만하게 만든다. 헛간·오두막에 쓴다.
  - 탑 지붕: 둥근 테두리에서 시작해 한 칸씩 안으로 좁히고, 꼭대기는 담장+울타리로 끝낸다.
  - 평지붕: 테두리 띠(반블록·계단)를 두르고, **높이가 다른 평지붕 여러 개**를 겹친다. 천창을 넣으면 실내도 밝아진다.
  - 모던 지붕선: 벽 꼭대기에 유리 띠를 두고, 그 위아래에 반블록 테두리를 반 칸씩 엇갈려 둘러 층을 만든다.
- **한 건물에 지붕 형태를 둘 이상** 쓴다. 단, 보조 지붕(지붕창·날개)은 본 지붕보다 작아야 한다.
- 지붕도 **그라데이션**이 된다. 예: 구리 산화 단계, 처마 쪽과 용마루 쪽 색 차이.
- 굴뚝: 블록 위 모닥불 + 둘레 트랩도어 + 위에 담장. 지붕보다 높이 솟아 강조점이 된다.
- → 도구: `gable`, `hip`, `curved_gable`, `flared_hip`, `eave_ring`, `cone`, `spire`, `flat_roof(parapet=, cap=)`, `Arch.grad`.

## 4. 매스(덩어리)와 모던 건물

- 모던 재료: 흰 바탕(석영·흰 콘크리트) + 대비색 1개(회색·검정 콘크리트) + 나무 1종 + 유리.
  - 조합 예: 흰색 + 회색 + 참나무 + 짙은 파란 유리 / 흰색 + 검정 + 자작나무 + 검은 유리 / 흰색 + 연회색 + 아카시아 + 연파랑 유리.
- 매스 문법:
  - **L자**: 흰 테두리 하나가 벽과 지붕을 감싼다. 그 안쪽을 다른 재료로 들여 현관을 만든다.
  - **S자(계단형)**: L을 위아래로 이어 1층 지붕이 2층 테라스가 되게 한다. 층마다 재료를 바꿀 수 있다.
  - 사각형만 쓰지 않는다. 원통·둥근 모서리 덩어리를 하나 섞으면 단조로움이 깨진다.
- 깊이는 앞뒤뿐 아니라 **위아래**로도 준다. 현관은 본채보다 앞으로, 2층은 1층보다 뒤로 물리고, 덩어리마다 바닥 높이를 다르게 한다.
- 문: 단순한 구멍 대신 **한 칸 들이고**, 문 위·옆에 유리를 둔다. 테두리에 다른 재료를 쓰고 위쪽에 띠를 둔다.
- 뒷면·옆면도 비워 두지 않는다. 외부 계단, 발코니, 두 번째 출입구처럼 **돌아다닐 길**을 둔다.

## 5. 실내: 3단계 순서

1. **마감(바닥·벽·천장)**
   - 천장: 반블록 사이에 트랩도어를 끼워 **들보처럼** 보이게 한다. 층고가 높으면 장식 들보로 공간을 나눈다.
   - 바닥: 껍질 벗긴 통나무를 방향을 바꿔 깔아 **체크무늬**를 만든다.
   - 계단은 바닥과 같은 나무로 만든다. 계단 밑은 책장·수납으로 채운다.
   - 바깥 벽을 들여 지었다면 실내 쪽 벽면도 따로 정리한다.
   - 창이 두 층에 걸쳐 있으면 그 자리에 다락 바닥을 깔지 않는다.
2. **큰 가구(쓰임)**
   - 방마다 쓰임을 먼저 정하고 침대·수납·작업대 같은 큰 물건부터 놓는다.
   - 계단 구멍 둘레는 울타리·문·트랩도어로 막는다. 트랩도어 칸막이로 공간을 나눈다.
   - 수납은 상자를 한 줄로 늘어놓고 통(barrel)과 섞는다.
3. **소품**
   - 빈 바닥에는 러그, 상판 위에는 등·화분·종을 놓는다. 벽에는 그림이나 액자를 걸되 주변에 여유를 둔다.
   - 블록 아래에 붙인 깃발은 수건이 되고, 압력판은 도마가 된다.

### 가구 문법 (반블록·계단·트랩도어)

| 가구 | 만드는 법 |
|---|---|
| 책상 | 양끝 계단 + 가운데 석영 + 위 반블록, 옆면 트랩도어 |
| 벽 선반 | 바닥 반블록 + 양끝 계단 + 위 반블록, 칸마다 화분·소품 |
| 침대 프레임 | 침대 끝에 표지판(발판), 머리 쪽에 통을 세워 협탁 |
| 소파 | 계단 줄 + 양끝 트랩도어 팔걸이 |
| 식탁 | 계단을 마주 보게 놓고 가운데 반블록 |
| 수납장 | 트랩도어 옆판 + 층마다 반블록 선반 |
| 옷장 | 갑옷 거치대를 트랩도어로 둘러싼다 |
| 부엌 | 석영 상판 + 화로 + 위 후드(굴뚝으로 연결) + 상부장 |
| 욕조 | 계단을 둘러 바닥을 낮춘 통 + 수도꼭지(버튼·레버) |
| TV 벽 | 검은 콘크리트 화면 + 아래 낮은 장 + 버튼 스피커 |

- → 도구: `table`, `chair`, `bed`, `rug`, `counter`, `shelf_wall`, `hang`, `stair_run`. **천장 들보, 침대 프레임, 계단 밑 수납은 아직 도구가 없다.**

## 6. 지금 템플릿에 적용할 것 (우선순위)

1. **창을 한 칸 들인다.** 창틀·창턱·인방을 붙인 `recessed_window`를 기본으로 쓴다. 단, 벽 두께가 1이라 실내 쪽이 튀어나오지 않게 바깥으로 틀을 낸다.
2. **모서리와 층 경계에 띠·기둥**을 넣는다. 층 사이 `cornice` 한 줄, 모서리 `pilaster`.
3. **지붕 처마를 1칸 이상** 내고, 끝에 뒤집힌 계단 테두리(`trim`)를 붙인다. 박공 폭은 홀수로 잡는다.
4. **천장 들보**: 반블록 천장 + 트랩도어 줄을 도구로 만든다(`Kit.beam_ceiling` 후보).
5. **현관을 초점으로** 둔다. 들인 문 + 위 유리 + 캐노피 + 양쪽 기둥처럼 깊이 층을 이곳에 모은다.
6. 실내는 마감 → 큰 가구 → 소품 순서로 만들고, 방마다 소품이 3개 이상 있는지 본다.

**적용 기록 (2026-11-15, `family_house`)**: 1·2·4·5번을 적용했다.
- 창: 들이지 않고 바깥에 트랩도어 세로틀을 달았다(`_win(frame=True)`). 인방은 층 띠 바로 밑에서 두 겹 선반처럼 보여 뺐다. 층 띠와 처마 반자가 창 머리 역할을 한다.
- 벽: y5에 층 띠를 둘렀다(현관 칸은 끊음). 현관 양옆에는 기둥을 세웠다.
- 실내: 1층 거실·부엌에 트랩도어 들보, 도마, 침대 발치 벤치를 넣었다.
- 점검: strict 0건을 유지했다. 3번(처마)은 원래 1칸에 홀수 폭이라 그대로 뒀다.

## 7. 점검에 추가할 만한 규칙 (qa.py 후보)

- 돌출부(2칸 이상 내민 바닥) 밑에 받침이 없으면 경고한다.
- 지붕 처마가 벽 바깥으로 나오지 않으면 경고한다.
- 넓은 벽면(가로 7칸 이상)이 한 평면이면 "깊이 없음"으로 경고한다.

## 8. 동아시아 기와지붕: 높이 지도 방식 (ㄱ자 한옥에서 처음 씀)

`village_real._wing_tops` + `_field_roof`.

- 지붕을 칸마다 높이(반 칸 단위)로 계산한 뒤 깐다. 홀수는 반블록, 짝수는 오르막을 향한 계단, 꼭대기는 꽉 찬 블록이다.
- 날개가 여럿이면(ㄱ·ㄷ자) 날개별 높이 지도의 **최댓값**을 쓴다. 그러면 안쪽 회첨(골)과 바깥 추녀가 저절로 생긴다.
- 곡선: 처마 쪽 4칸은 반 칸씩, 그 위는 한 칸씩 올린다. **한 번에 한 칸 넘게 뛰면** 계단식 벽이 생겨 테라스처럼 보인다(첫 시도에서 실패).
- 팔작: 끝 3칸만 모임지붕, 안쪽은 맞배다. 높이가 뛰는 경계 칸을 널판으로 채우면 합각벽이 된다.
- 앙곡: 모서리 2칸을 반 칸~한 칸 들어 올린다. 들린 칸 밑은 이웃 높이까지 채워 떠 있지 않게 한다.
- 각 칸은 이웃 칸 블록 높이까지 아래를 채운다. 그래야 지붕 틈으로 바깥 공기가 새지 않는다(strict 외피 검사 통과).
- 용마루는 반블록 한 줄이다. 꽉 찬 블록을 더 얹으면 두 칸 높이 벽처럼 보인다.
- 트인 공간(대청)과 닫힌 공간(부엌)이 다락으로 이어지면 외피 구멍이 된다. 칸막이벽을 지붕 밑까지 올려 막는다(`_seal_up`).

## 9. 마크 블록 작용: 플러그인은 물리 없이 놓는다

플러그인은 `block.setBlockData(data, false)`로 놓는다(`BuildManager.java`). 물리 업데이트가 없어서 **템플릿에 적힌 상태가 그대로 게임에 나온다**. 손으로 놓을 때 게임이 자동으로 계산해 주던 것을 템플릿이 미리 채워야 한다. `Kit.settle()`이 그 일을 한다.

| 블록 | 그대로 두면 | `settle()`이 하는 일 (바닐라 규칙) |
|---|---|---|
| 계단 | `shape=straight`라 지붕 모서리·골이 어긋난다 | `StairBlock.getStairsShape`. 앞(facing 쪽) 이웃이 꺾인 계단이면 바깥 모서리, 뒤면 안쪽 모서리. left/right는 facing의 반시계 방향 기준 |
| 울타리 | 이웃과 안 이어져 기둥만 선다 | 같은 종류 울타리(나무끼리, 네더 벽돌끼리), 축이 맞는 울타리 문, 면이 꽉 찬 블록에 붙는다 |
| 판유리·철창 | 얇은 기둥만 남는다 | 판유리·철창·담장·꽉 찬 면에 붙는다 |
| 담장 | 사방 기둥 | 담장·판유리·울타리 문·꽉 찬 면에 붙는다. 곧은 두 면만 이어지면 위 기둥을 뺀다 |
| 나뭇잎 | `persistent=false, distance=7`이라 **시간이 지나면 썩어 사라진다** | `persistent=true` |

- 면이 꽉 차지 않은 블록(반블록·계단·문·트랩도어·상자·침대·화분·랜턴 등)에는 울타리 등이 붙지 않는다. `_NOT_STURDY` 목록 참고.
- 문은 위·아래 짝, 침대는 머리·발 짝, 매다는 등은 위 블록, 사다리는 뒤 벽이 필요하다. `qa.check`가 검사한다.
- 모닥불 연기는 위가 막히면 고인다. 굴뚝 속을 비워 연도를 만든다.
- 자막 실험에서 확인한 것: 계단을 오를 때 머리 위 2칸이 필요하다. 마지막 단 바로 위 칸까지 위층 바닥을 뚫어야 올라갈 수 있다.

**적용 범위**: `settle()`은 지금 `medieval_inn()`만 부른다.
- 기존 템플릿의 나뭇잎은 이미 `persistent=true`라 썩지 않는다(2026-11-15 확인).
- 이웃과 안 이어진 울타리는 14종에 있다(엘프 나무 집 17개, 한옥 8개, 단독주택 6개 등). 탁자 다리처럼 일부러 기둥만 둔 것도 섞여 있다.
- 계단 모서리도 직선으로 남아 있다.
- 기존 템플릿에 넓히면 게임에서 모양이 달라지므로, 템플릿마다 렌더링으로 확인하면서 적용한다.
